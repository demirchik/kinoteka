# Проверка отзывов

Проверка выполнена HTTP-запросами через формы приложения на отдельной копии учебной базы.

| Действие | Наблюдаемый результат |
|---|---|
| Лира создаёт фильм, сохраняет отзыв и меняет оценку на 10 | В карточке остаётся один отзыв Лиры с новой оценкой |
| Кадр входит и оставляет отзыв о том же фильме | В карточке видны оба отзыва |
| Кадр удаляет свой отзыв | Отзыв Лиры остаётся в карточке |
| Пользователь удаляет тестовый фильм | Запрос его карточки через API возвращает 404 |
| Гость пытается создать фильм через API | Сервер возвращает 401 |

Автор отзыва определяется по серверной сессии. Ограничение Movie и Review задаётся в prisma/schema.prisma: пара movieId и author уникальна, удаление фильма каскадно удаляет связанные отзывы.
