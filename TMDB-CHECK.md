# Проверка TMDB

28 ноября 2026 года серверный модуль приложения выполнил запрос к TMDB с действующим токеном. Поиск «Железный человек» вернул фильм с идентификатором 1726. Запрос карточки по этому идентификатору вернул «Железный человек», 2008 год. В рабочей SQLite-базе команды найдена сохранённая запись с тем же названием и tmdbId.

Для повторения войдите как Лира, откройте вкладку TMDB, найдите фильм и сохраните его. Затем откройте коллекцию и найдите карточку по названию. У импортированного фильма в Movie заполнен tmdbId. У четырёх вымышленных фильмов исходной коллекции это поле пустое.

Без токена вкладка TMDB показывает сообщение о резервном режиме и результаты из SQLite. Для демонстрации этого сценария достаточно исходной копии проекта без файла .env.local.
