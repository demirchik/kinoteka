# Показ «Кинотеки» на защите

Откройте ветку develop и запущенную «Кинотеку». В исходной коллекции четыре вымышленных фильма, восемь отзывов и локальные постеры.

1. На вкладке «Коллекция» введите «частота». Откройте «Полярную частоту», покажите описание и отзывы.
2. Войдите как Лира (lira / kinolira). Во вкладке TMDB найдите «Железный человек», 2008. Откройте карточку и сохраните фильм. Если он уже сохранён, приложение откроет локальную карточку.
3. Добавьте свой отзыв и смените оценку. Покажите, что количество отзывов после редактирования сохранилось. При отсутствии сети выполните этот шаг на «Полярной частоте» — у Лиры там уже есть отзыв.
4. Если преподаватель попросит показать создание и удаление, добавьте временный фильм через «Добавить фильм», измените описание, затем удалите его через редактор.

## Что объяснить по коду

- lib/tmdb.ts получает название, год, описание и путь к постеру. Токен используется на сервере.
- prisma/schema.prisma связывает Review с Movie по movieId. Уникальный tmdbId позволяет повторно открыть импортированный фильм. Пара movieId и author ограничивает автора одним отзывом на фильм.
- lib/auth.ts находит сессию по хешу случайного токена из cookie. Серверные действия берут имя автора из сессии.
- В офлайн-режиме приложение читает фильмы и отзывы из SQLite. У исходных фильмов постеры локальные. Для сетевого постера предусмотрена заглушка.
