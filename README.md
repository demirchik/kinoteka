# Кинотека

Учебный каталог для зрителей, которые хотят найти фильм, сохранить его в коллекции и обсудить с друзьями. Локальная коллекция, постеры демонстрационных фильмов и отзывы открываются без доступа к TMDB.

**УП.01, тема № 22 «Каталог фильмов с TMDB API».** ГБПОУ НСО «Новосибирский строительно-монтажный колледж», ИСП 24-1. Срок по заданию — 16–28 ноября 2026 года, 10 рабочих дней, 72 академических часа.

## Локальный запуск

Понадобятся Git и Node.js 22.16 или новее с npm. Интернет нужен при первой установке зависимостей и движка Prisma. Если уже распаковали комплект, откройте терминал в папке с `package.json`. Чтобы получить проект с GitHub, выполните в PowerShell:

```powershell
$repo = Read-Host "Введите HTTPS-адрес репозитория GitHub"
git clone --branch develop $repo kinoteka
cd kinoteka
```

Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). В комплекте есть мигрированная база `prisma/dev.db`, повторная подготовка для первого запуска не требуется. Для остановки нажмите Ctrl+C.

## Демо и проверка

| Пользователь | Логин | Демо-пароль |
|---|---|---|
| Лира | lira | kinolira |
| Кадр | kadr | kinokadr |

1. Откройте коллекцию. В ней четыре вымышленных фильма с локальными постерами и восемь отзывов. Найдите «ЧАСТОТА» и откройте карточку.
2. Без токена откройте вкладку TMDB. Появится сообщение о переходе на локальную коллекцию. Поиск продолжит работать.
3. Войдите как Лира, добавьте фильм, откройте его карточку и измените описание. Создайте отзыв с оценкой от 1 до 10 и измените свою оценку.
4. Выйдите, войдите как Кадр и откройте тот же фильм. Отзыв Лиры доступен для чтения. Добавьте второй отзыв, затем удалите свой. После перезапуска сервера изменения сохраняются.
5. В редакторе тестового фильма раскройте «Удалить фильм» и подтвердите. Связанные отзывы удалятся вместе с ним. Гостям доступны каталог и карточки. Оба демо-пользователя могут управлять общей коллекцией.

## Внешний каталог

Для проверки онлайн-режима скопируйте `.env.example` в `.env.local`, укажите свой **TMDB API Read Access Token** в `TMDB_READ_TOKEN` и перезапустите сервер. Переменная нужна только серверу. На вкладке TMDB пустая строка поиска показывает первую страницу популярных фильмов, введённое название запускает поиск. В карточке вошедший пользователь может сохранить фильм в SQLite. Повторное открытие сохранённой карточки ведёт к локальной записи.

Сервер запрашивает `/movie/popular`, `/search/movie` и `/movie/{id}` на русском языке. Интервал обновления кэша Next.js — 30 минут, тайм-аут запроса — 4 секунды. При ошибке сети или авторизации список переключается на локальные данные. Для ещё не импортированной карточки доступна ссылка в коллекцию. Постеры импортированных фильмов загружаются с TMDB, недоступное изображение заменяется заглушкой. Описания сохранённых фильмов и отзывы остаются в SQLite. [Документация TMDB](https://developer.themoviedb.org/reference/search-movie)

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Устройство проекта

Next.js 15.5.29 (App Router), React, TypeScript, Tailwind CSS 3, Prisma 6.19 и SQLite. Серверные компоненты читают данные, Server Actions обрабатывают формы. Сессия действует восемь часов. В HttpOnly-cookie хранится случайный токен, в таблице Session — его SHA-256, псевдоним и срок действия. Выход удаляет сессию.

| Модель | Назначение |
|---|---|
| Movie | Карточка фильма, необязательный уникальный tmdbId, жанр, год, описание и путь к постеру |
| Review | Текст, оценка и автор. У фильма много отзывов, у автора один отзыв на фильм |
| Session | Серверное состояние входа вымышленного пользователя |

| Маршрут | Возможности |
|---|---|
| `/`, `/?source=tmdb` | Коллекция, внешний каталог и поиск |
| `/movies/[id]`, `/tmdb/[id]` | Локальная карточка с отзывами, карточка внешнего фильма |
| `/movies/new`, `/movies/[id]/edit`, `/login` | Создание, редактирование и вход |
| `/api/movies` | GET — список и фильтр q, POST — создание |
| `/api/movies/[id]` | GET — карточка с отзывами, PUT — изменение, DELETE — удаление |

JSON для POST и PUT содержит `title`, `genre`, `summary` и необязательный `year`. Для записи нужна cookie-сессия. Ответы API различают неверные данные (400), гостя (401) и отсутствующую карточку (404).

## База и сборка

Prisma использует путь `file:./dev.db` относительно `prisma/schema.prisma`. В чистой копии без файла базы выполните:

```sh
npm run db:setup
```

Команда применяет миграции и запускает seed. При повторном запуске существующие демонстрационные записи сохраняются. Seed предназначен для учебной базы. В репозитории хранится исходный снимок. Для демонстрации удаления используйте новый фильм. Изменённый файл базы и активные сессии не включайте в следующие коммиты.

```sh
npm run lint
npm run typecheck
npm run build
```

После сборки можно выполнить `npm start`. Для просмотра таблиц выполните `npx prisma studio`. Короткий показ приложения описан в [сценарии защиты](TEAM.md).
